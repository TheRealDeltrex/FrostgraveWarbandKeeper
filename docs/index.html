Frostgrave Warband Keeper

A local warband tracker for Frostgrave (2nd Edition). No login, no server, no cloud — download it and everything runs on your own PC with your warbands saved as plain files, or play entirely in your browser.

Not affiliated with Osprey Games / Joseph A. McCullough.

▶ Play online — no download vDEV

Run the full app right in your browser. It works exactly like the desktop version — including custom pictures — and your warbands are saved in this browser, so closing the tab or refreshing is safe. That storage is per-browser though (this device, this browser only), so use “Export warband” for a portable backup or to move a warband to another browser or device. Custom pictures don't come back on import, so re-upload them if you reload a warband there. First load fetches a runtime, so give it a few seconds.

🪟 Windows vDEV

No Python install needed.

  1. Unzip it anywhere (e.g. your Desktop or Documents).
  2. Run FrostgraveWarbandKeeper.exe inside the unzipped folder.
  3. It opens in your browser automatically. A tray icon lets you quit it later.

The exe is signed (“Deltrex”), but with a self-signed certificate rather than a paid one, so SmartScreen may still warn the first time — click “More info” → “Run anyway”.

🐧 Linux vDEV

No Python install needed.

  1. Extract it: tar -xzf FrostgraveWarbandKeeper-linux-x64.tar.gz
  2. Make it executable: chmod +x FrostgraveWarbandKeeper
  3. Run it: ./FrostgraveWarbandKeeper — opens in your browser automatically.

Or from a file manager: right-click → Properties → allow executing, then double-click.

What it does

  • Create a warband: wizard, spells with casting numbers (own/aligned/neutral/opposed), and an optional apprentice.
  • Autosave: most fields save the instant you change them, keeping your scroll position and open cards intact — no Save button to remember.
  • Wizard states: Lich, Beastcrafter, and Demonic Pacts, plus grave mutations for wizard, apprentice, captain, and soldiers.
  • Between games: level up (reversible), record post-game loot with a rulebook → item picker, and manage a combined Treasury, Vault and Workshop card.
  • Soldiers: hire from the full 2e roster on the warband page, track status, reorder, optionally level up, with an optional Edition-2 cost/gear house rule.
  • Captains: an optional, fully-tunable house rule for hiring or promoting a Captain, tricks, and absolute stat limits.
  • Home base locations and resources, the full Frostgrave Lexicon (spells, arms & armour, bestiary, magic items, loot & random encounter tables), and a clean PDF roster export plus JSON export/import.
  • Homerules covering most of the above, tunable per warband.
